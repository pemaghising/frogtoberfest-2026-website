<h1 align="center">Frogtoberfest 2026</h1>
<p align="center">Agent Forge &mdash; marketing site for Leapfrog's 2026 Frogtoberfest challenge.</p>

## Requirements

- Node v18+

## Running the App

```bash
$ yarn
$ yarn start
```

Opens at [http://localhost:3000](http://localhost:3000).

## Building for Production

```bash
$ yarn build
```

Outputs a static bundle to `build/`.
